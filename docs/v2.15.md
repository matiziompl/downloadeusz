Data: 2026-11-08

## Naprawiono

- Wybór propozycji beets przeniesiono poza zwinięte szczegóły. Kółko wyboru jest teraz widoczne przy nazwie nagrania, a szczegóły mają oddzielną etykietę „Szczegóły propozycji”.
- Komunikat o starszej propozycji wymagającej ponownego rozpoznania jest widoczny bez rozwijania szczegółów. Wcześniej użytkownik widział nieaktywny przycisk zastosowania bez widocznej kontrolki wyboru ani wyjaśnienia.
- Wskazówka przy przycisku wyjaśnia, że zaznaczenie kółka włącza zastosowanie propozycji. Uaktualniono instrukcję, README i oznaczenia wersji do 2.15.

## Weryfikacja

- Nowy test regresji odtworzył ukrycie kontrolki i komunikatu przy zamkniętych szczegółach; przed poprawką nie przechodził, po poprawce przeszedł.
- Wszystkie 27 testów Node frontendu oraz sprawdzenie składni JavaScript przeszły.
- Nie zmieniono mechanizmu zapisywania metadanych, API ani HAPI Runnera. Nie uruchamiano przeglądarki ani wdrożenia na Serweuszu. Sam zrzut nie potwierdza błędu zapisu po zaznaczeniu propozycji; weryfikacja dotyczy widocznego problemu z kontrolką wyboru.
