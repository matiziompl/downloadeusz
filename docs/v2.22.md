# Downloadeusz v2.22

Data: 2026-11-09

## Dodano

- Odnośniki **Szukaj w MusicBrainz** i **Szukaj tylko tytułu** przy polu linku w edytorze utworu. Pierwszy przygotowuje wyszukiwanie nagrań po tytule i wykonawcy, a drugi po samym tytule. Wyniki otwierają się w osobnej karcie; wybrany utwór i formularz pozostają na miejscu.
- Zapytania używają pól `recording` i `artist` w wyszukiwaniu zaawansowanym MusicBrainz. Znaki specjalne składni i adresu są kodowane osobno, a Unicode zachowywany. Album zastępczy nie jest filtrem, a oznaczenia wersji nagrania pozostają w tytule. Przy braku wykonawcy wyszukiwanie obejmuje sam tytuł; bez tytułu odnośniki są ukryte.

## Zmieniono

- README i instrukcja opisują przejście z wyszukiwania do wklejenia adresu konkretnego wpisu MusicBrainz. Zsynchronizowano wersję API, README, etykietę Dockerfile i tag Compose do 2.22.

## Weryfikacja i ograniczenia

- Pięć nowych testów najpierw odtworzyło brak generatora i odnośników, a po implementacji przeszło. Sprawdzają zapytanie tytuł–wykonawca, pominięcie albumu, szerszy wariant, brak danych, zmianę wybranego utworu, Unicode, znaki specjalne i zabezpieczenie parametrów adresu oraz otwieranie osobnej karty.
- Cały zestaw **75 testów frontendu**, składnia JavaScript i **11 testów dokumentacji oraz wersji API** przeszły. API sprawdzano przez TestClient w pamięci, z tymczasową konfiguracją.
- Kontrola HTML i wyrażeń Alpine przeszła; identyfikatory są unikalne. Statyczny detektor całego HTML zgłosił 39 ostrzeżeń; nie jest to pełny audyt dostępności. Przykład Compose w README jest identyczny z plikiem źródłowym, a numery wersji są zgodne.
- Symulacja kompletnego bloku aktualizacji z atrapą Dockera potwierdziła kopiowanie wszystkich modułów, zachowanie kont, `.env`, danych i `.git`, zatrzymanie przed wyłączeniem usługi przy brakującym module oraz brak kopiowania i budowania po błędzie zatrzymania.
- Nie uruchamiano przeglądarki, Playwrighta, żywego wyszukiwania MusicBrainz ani wdrożenia. Testy potwierdzają generowany adres i logikę interfejsu, nie zawartość wyników zewnętrznego serwisu.
