# Downloadeusz v2.19

Data: 2026-11-09

## Zmieniono

- Ustawienia otwierają się jako wyśrodkowane okno pop-up, tak jak dokumentacja i Normalizeusz, zamiast wysuwać się z prawej krawędzi. Koło zębate pozostaje w prawym górnym rogu.
- Zachowano wszystkie dotychczasowe opcje wyglądu, integracji i prezentacji statusu oraz wersję pobieraną z API. Paleta motywu korzysta z mniejszej liczby kolumn na telefonach.
- Okno ma przewijaną treść i stale widoczny nagłówek. Można je zamknąć przyciskiem X, klawiszem Escape lub kliknięciem tła poza nim. Natywny dialog ogranicza fokus do okna; po zamknięciu fokus wraca do koła zębatego, a przewijanie strony jest przywracane. Zamknięcie zachowuje preferencje.
- Zabezpieczono ustawienia, dokumentację i Normalizeusza przed jednoczesnym otwieraniem. Otwarcie ustawień zamyka panel błędów. Usunięto animację wysuwania i osobną nakładkę ustawień.
- README i instrukcja opisują nowe okno. Zsynchronizowano wersję API, README, etykietę Dockerfile i tag Compose do 2.19.

## Weryfikacja i ograniczenia

- Składnia JavaScript i 42 testy frontendu przeszły. Cztery nowe testy najpierw wykazały brak obsługi pop-upu, a po zmianie potwierdziły otwieranie, zamykanie, zachowanie preferencji, przywracanie przewijania i fokusu, ochronę przed nakładaniem dialogów oraz sprzątanie przy usunięciu komponentu.
- Analiza HTML potwierdziła zrównoważone znaczniki, trzy dialogi poza formularzami, unikalne identyfikatory i obecność powiązań ustawień. Przykład Compose w README jest identyczny z plikiem źródłowym; numery wersji są zgodne.
- 11 testów dokumentacji i wersji API przeszło przez FastAPI TestClient w pamięci, z użyciem istniejącego środowiska testowego i tymczasowej konfiguracji. Systemowy Python nie zawierał zależności `mediafile`.
- Zweryfikowano kompletny zestaw źródeł aplikacji do kopiowania. Symulacja aktualizacji z atrapą Dockera potwierdziła zachowanie plików kont, `.env`, danych i `.git`, przerwanie przed zatrzymaniem usługi przy brakującym źródle oraz brak kopiowania i uruchamiania po błędzie zatrzymania.
- Nie uruchamiano przeglądarki, Playwrighta, obrazu Docker ani usług produkcyjnych. Testy bez przeglądarki nie potwierdzają wyglądu ani natywnej obsługi klawiatury. Statyczny detektor UI zgłosił ostrzeżenia dla istniejących elementów HTML, m.in. kontrastu i zagnieżdżonych kart.
