# Downloadeusz v2.3

Data: 2026-11-07

Zmiany względem v2.2.

## Dodano

- Widżet dokumentacji w lewym górnym rogu, otwierający wyśrodkowane okno z zakładkami **README**, **Ostatnia wersja** i **Instrukcja**.
- Odczyt README, opisu bieżącej wersji oraz instrukcji bezpośrednio z plików Markdown. Dokumenty są dołączane do obrazu Dockera.
- Instrukcję pobierania przez SpotDL, yt-dlp i Soulseek, kolejki i ponowień, beets, metadanych i komend FFmpeg, playlist, integracji Navidrome/slskd/Normalizeusz, panelu błędów i ustawień wyglądu.
- Obsługę klawiatury i zamykania okna dokumentacji przez Escape, tło i przycisk zamknięcia oraz komunikaty wczytywania, błędów i ponawiania.
- `AGENTS.md` z zasadami numerowania i osobnych opisów każdej kolejnej wersji w `docs/`, przejętymi z HAPI i dostosowanymi do Downloadeusza. Historia prowadzona według tych zasad zaczyna się od tej wersji.

## Zmieniono

- Tytuł karty przeglądarki na **Downloadeusz**.
- Położenie widżetu błędów: znajduje się pod przyciskiem dokumentacji.
- Prezentację wersji w ustawieniach: numer pochodzi z API aplikacji.
- Nagłówek README na zwykły Markdown, aby poprawnie wyświetlał się w aplikacji bez surowego HTML i niedostępnej grafiki.
