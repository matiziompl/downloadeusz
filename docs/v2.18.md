# Downloadeusz v2.18

Data: 2026-11-08

## Zmieniono

- Cały panel Normalizeusza przeniesiono z formularza strony głównej do osobnego okna pop-up. Widżet otwierający znajduje się w lewym górnym rogu, bezpośrednio pod przyciskiem dokumentacji. Widżet błędów przesunięto pod Normalizeusza.
- W oknie dostępne są dotychczasowe funkcje: stan i odświeżanie usługi, przełącznik **ReplayGain po imporcie**, ręczne operacje ReplayGain i albumów, postęp, historia zadań oraz raporty i błędy. Otwarcie odświeża stan; zamknięcie pozostawia zadania i ustawienia bez zmian.
- Okno korzysta z natywnego dialogu, przewijanej treści, przycisku zamknięcia, Escape i zamykania kliknięciem tła poza oknem. Po zamknięciu fokus wraca do widżetu.
- Lewe widżety są ukrywane podczas wyświetlania panelu błędów, aby nie zasłaniały jego treści. Wracają po zamknięciu panelu lub opróżnieniu listy błędów.
- README i instrukcja opisują nową lokalizację panelu. Zsynchronizowano wersję API, README, etykietę Dockerfile i tag Compose do 2.18.

## Weryfikacja i ograniczenia

- Testy dokumentacji, API Normalizeusza i trwałego przełącznika: 70 przeszło; API sprawdzano przez TestClient w pamięci. Nie zmieniono zachowania integracji poza prezentacją panelu.
- Składnia JavaScript i 38 testów frontendu przeszły. Sprawdzono logikę otwierania i zamykania, odświeżenia przy otwarciu, przywracania przewijania i fokusu, ochrony przed nakładaniem dialogów, zachowania trwających operacji oraz widoczność lewych ikon przy panelu błędów. Testy nowego okna odtworzyły brak funkcji przed implementacją; dodatkowy test kolizji ikon również najpierw odtworzył problem.
- Niezależna analiza HTML potwierdziła jeden dialog Normalizeusza poza formularzami, komplet kontrolek wewnątrz niego i 14 unikalnych stałych identyfikatorów. Przykład Compose w README porównano z plikiem źródłowym. Blok aktualizacji sprawdzono w izolowanej symulacji z atrapą Dockera: zachowuje konta, `.env` i dane, a brak źródła przerywa wykonanie przed zatrzymaniem usługi.
- Nie uruchamiano przeglądarki, Playwrighta, obrazu Docker ani produkcyjnych usług. Kontrola kodu nie potwierdza wyglądu ani pełnej zgodności WCAG. Statyczny detektor UI zgłosił ostrzeżenia dla istniejącego HTML.
