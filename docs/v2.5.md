# Downloadeusz v2.5

Data: 2026-11-07

Zmiany względem v2.4.

## Dodano

- Wyszukiwanie Soulseek w maksymalnie czterech coraz ogólniejszych, niepowtarzających się zapytaniach, ze wspólnym limitem około minuty. Kolejne próby obejmują pełnego wykonawcę i tytuł, skróconego wykonawcę i tytuł, sam tytuł oraz charakterystyczne słowa długiego tytułu.
- Czyszczenie dodatków publikacji, np. „Official Audio”, oznaczeń wydania, np. „Remastered 2011”, oraz powtórzonego wykonawcy w rozpoznanych tytułach publikacji. Wyniki nadal muszą odpowiadać wykonawcy, tytułowi, wersji i dostępnej długości nagrania. Oznaczenia faktycznie innej wersji, np. live i remix, pozostają chronione; niejednoznaczne mieszane dopiski są zachowywane.
- Album zastępczy nazwany jak utwór, gdy po próbach rozpoznania nowy import nadal nie ma wiarygodnego albumu. Pochodzenie zastępcze jest zapisywane i nie potwierdza wydania. Istniejące poprawne albumy oraz oryginalne pliki pozostają chronione.
- Kafelek **Aktualne zadanie** między formularzem a kolejką: etap, utwór, globalne liczniki, zapytanie Soulseek i numer próby oraz rzeczywiste oczekiwanie na dalsze przetwarzanie.

## Zmieniono

- API kolejki zwraca bezpieczne podsumowanie bieżącej pracy, niezależne od 50 ostatnich zadań i stronicowania utworów. Wybór zadania w historii nie przełącza kafelka bieżącej pracy.
- Zmiana etapu czyści nieaktualne zapytanie wyszukiwania, a zakończenie i finalizacja usuwają wskazanie poprzedniego utworu.
- README oraz instrukcję obsługi zgodnie z nowym wyszukiwaniem, albumami i prezentacją postępu.

## Weryfikacja i ograniczenia

- Pełny zestaw backendu: **347 zaliczonych, 1 pominięty**. Po końcowej poprawce czyszczenia oznaczeń wydania uruchomiono ponownie testy wyszukiwania, metadanych i albumów: **95 zaliczonych**.
- Testy postępu kolejki, API i uruchamiania backendu: **24 zaliczone**. Testy JavaScript kafelka: **7 zaliczonych**; `node --check` oraz `git diff --check` zakończyły się powodzeniem.
- Regresje importera i beets: **94 zaliczone, 1 pominięty**, dodatkowo **2 zaliczone** przypadki zachowania prawdziwego albumu, również albumu o nazwie „Single”. Pominięty test rzeczywistego odcisku Chromaprint wymaga niedostępnego lokalnie `fpcalc`.
- Statyczny detektor stylu wskazuje ograniczenia istniejącego interfejsu (m.in. kontrast i zagnieżdżone karty); wynik nie zastępuje sprawdzenia wyglądu w przeglądarce.
- Nie uruchamiano przeglądarki, Playwrighta ani wdrożenia na Serweuszu. Frontend jest statyczny i nie ma osobnego procesu budowania.
- Weryfikacja wyszukiwania korzysta z odpowiedzi slskd odtwarzanych w pamięci; nie potwierdza bieżącej dostępności konkretnych nagrań w sieci Soulseek.
