# Downloadeusz v2.16

Data: 2026-11-08

## Dodano

- Graf strukturalny kodu aplikacji i testów w `graphify-out/`: interaktywny HTML, dane JSON, raport z nazwami społeczności, diagnostyka oraz surowe wyniki spójności. Zakres obejmuje 58 plików Python i JavaScript z bieżącego drzewa roboczego, także wcześniejsze niezatwierdzone zmiany. Po scaleniu graf zawiera 960 węzłów, 2706 połączeń i 36 społeczności.

## Zmieniono

- README i instrukcja wyjaśniają wyłączanie osobnego Normalizeusza: `NORMALIZATION_ENABLED=false` wymaga odtworzenia kontenera Downloadeusza. Zwykłe pobieranie i import mogą wtedy kontynuować bez potwierdzenia ReplayGain; ręczne zadania Normalizeusza nadal go wymagają.
- Doprecyzowano brak limitu czasu oczekiwania na normalizację przy włączonej integracji oraz zachowanie już wysłanych zleceń po jej wyłączeniu. Nie zmieniono logiki wykonawczej ani domyślnych ustawień integracji.
- Zsynchronizowano wersję API, README, etykietę Dockerfile i tag obrazu Compose.

## Weryfikacja i ograniczenia

- 41 testów `test_pipeline.py` i `test_normalizer_api.py` przeszło. Dodatkowe scenariusze z tymczasową bazą i atrapą Navidrome potwierdziły: oczekiwanie bez ACK również po przesunięciu czasu o rok, kontynuację już oczekującego pobierania po wyłączeniu integracji, zachowanie ręcznego zlecenia oraz wykonywanie innych gotowych zadań.
- Końcowy wspólny przebieg `test_documentation.py`, `test_runtime_entrypoint.py`, `test_pipeline.py` i `test_normalizer_api.py`: 58 testów przeszło. Testy API używały TestClient w pamięci. Początkowy błąd importu wynikał z braku `ffmpeg` w `PATH`; po dodaniu katalogu istniejącego środowiska testowego testy przeszły bez zmiany kodu. Przykład Compose w README porównano z plikiem źródłowym, a wersje i integralność artefaktów sprawdzono programowo.
- Graf utworzono przez Graphify bez semantycznego przetwarzania dokumentów: 0 tokenów wejścia i wyjścia LLM w ekstrakcji. Nie indeksowano sekretów, danych wykonawczych ani innych projektów.
- Diagnostyka ekstrakcji wykazała 488 relacji z nierozwiązanym końcem, jedną pętlę własną oraz 144 relacje scalone między tymi samymi końcami. Relacje oznaczone `INFERRED` są heurystykami ekstraktora i wymagają weryfikacji w źródłach. Graf nie modeluje kompletnej infrastruktury usług ani konfiguracji Compose; metody obiektów JavaScript mogą nie mieć osobnych węzłów.
- Niezależny przegląd potwierdził zakres grafu, zgodność dokumentacji ze źródłami, aktualność skrótów kodu i ponownie 58 poprawnych testów. Widok HTML wymaga dostępu do `unpkg.com`, skąd pobiera bibliotekę wizualizacji.
- Nie uruchamiano przeglądarki, budowania obrazu Docker ani usług produkcyjnych. Wnioski o Normalizeuszu dotyczą kodu i testów, nie potwierdzają montowań ani ustawień działającej instalacji.
