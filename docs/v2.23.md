# Downloadeusz v2.23

Data: 2026-11-09

## Naprawiono

- Zapis metadanych FLAC nie używa już `pop(key, default)` nieobsługiwanego przez komentarze Vorbis biblioteki Mutagen. Znacznik albumu zastępczego jest usuwany po sprawdzeniu jego obecności. Naprawa obejmuje zastosowanie wybranych danych MusicBrainz i akcję **Nazwij album tytułem piosenki**, zarówno z istniejącym znacznikiem, jak i bez niego.
- Zadania nie zatrzymują się już na tym błędzie zapisu i nie trafiają z jego powodu w kolejne oczekiwanie na ponowienie. Nie zmieniono danych istniejącej kolejki ani reguł ponawiania.

## Zmieniono

- README i instrukcja opisują wznowienie wcześniejszych nieudanych edycji FLAC po aktualizacji, w tym konieczność nowego podglądu przy jego wygaśnięciu lub zmianie pliku. Zsynchronizowano wersję API, README, etykietę Dockerfile i tag Compose do 2.23.

## Weryfikacja i ograniczenia

- Cztery testy na rzeczywistych plikach FLAC najpierw odtworzyły błąd `pop expected at most 1 argument, got 2` i stan kolejki `waiting`, a po poprawce przeszły ze stanem `done` bez nieudanych prób. Obejmują obie operacje oraz obecny i nieobecny znacznik.
- Testy uruchamiają rzeczywisty edytor i trwałego workera na plikach w katalogach tymczasowych. Potwierdzają zapis tagów, uporządkowanie ścieżki, zachowanie sygnatury audio i nienaruszenie źródłowego pliku. Odpowiedzi MusicBrainz i pobieranie okładki są zastąpione kontrolowanymi odpowiedziami.
- Łącznie **106 testów edytora, rzeczywistych plików FLAC, indeksu, API biblioteki, mapowania ścieżek, MusicBrainz, okładek, anulowania zadań i dokumentacji przeszło**. API sprawdzano w pamięci przez TestClient. Nie uruchamiano całego zestawu backendu ani testów frontendu, ponieważ poprawka dotyczy jednego miejsca w zapisie tagów.
- `git diff --check`, spójność wersji i identyczność przykładu Compose w README z plikiem źródłowym sprawdzono pomyślnie. Symulacja kompletnego bloku aktualizacji z atrapą Dockera zachowała pliki kont, `.env`, dane i `.git`, przerwała aktualizację przed zatrzymaniem przy brakującym module oraz nie kopiowała ani nie budowała po błędzie zatrzymania.
- Nie uruchamiano przeglądarki, Playwrighta, wdrożenia ani usług produkcyjnych. Nie modyfikowano muzyki ani kolejki użytkownika.
